
# Kpata Academy - 15 Free Certs Roadmap - Self Paced
Self-paced AI Academy with 15 internationally recognized FREE certifications.

## Deploy to Vercel
1. Upload this frontend folder to GitHub
2. Import to Vercel
3. Add Env Vars in Vercel:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
4. Deploy
